# React AutoComplete Search

A React autocomplete search component built using:

- React Hooks
- useState
- useEffect
- Fetch API
- Debouncing
- Dynamic Rendering

## Features

- Real-time search suggestions
- Debounced API requests
- Dynamic rendering using map()
- Clean and responsive UI

## Learning Outcomes

- State Management
- Effect Cleanup Functions
- Event Loop & Debouncing
- API Integration
